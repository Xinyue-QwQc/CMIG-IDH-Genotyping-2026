# Distributed and Separate Assets

The repository distributes model source, pseudonymous study partitions and patient-group mappings, fixed-model predictions, statistical code, derived summaries, and timing measurements.

MRI volumes and original clinical tables remain with their dataset providers. The evaluated study checkpoint, fixed description embedding, and third-party pretrained weights are obtained separately. The five evaluation/timing tools and two 3DINO configuration files are supplied in the CMIG manuscript Supplementary package.

The distributed analysis manifests and predictions use study pseudonyms. Historical model source may retain public dataset example filenames and local filesystem paths. Asset preparation is documented in [Installation](../docs/installation.md) and [Data access](../docs/data_access.md).
